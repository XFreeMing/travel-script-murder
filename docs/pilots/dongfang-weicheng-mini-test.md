## 准备

- 一名孩子与一名参与家长；也可以增加一名孩子。
- 一位引导者负责发卡、读开场和记录。引导者不计入家庭玩家人数。
- 一份下方的“家长便条”、一张[儿童搬运标签](dongfang-weicheng-label.svg)和一张[共同查看的小屋图](dongfang-weicheng-cards.svg)，分别打印或展示。
- 一个任意纸片代表找到的灯。口头说明代表灯即可，不需要购买道具。

引导者先读完整页。参与家长只阅读发给自己的便条，不预先阅读下方答案。把搬运标签单独交给孩子，家长拿短便条，两人共同看房屋图。请孩子主动描述或展示标签，家长等孩子提供这条信息后再一起判断。用屏幕时也分别展示，孩子可随时重新看标签，不考记忆。

## 开场

引导者读：“你们是今天的守灯小队。灯会要用的灯被搬去暂存了，我们刚找到了守灯员留下的便条。请一起找到放灯的小屋，再把位置告诉灯会组织者。”

本小样从故事中间开始，集中测试选屋这一环节。寻找便条、还原完整经过与结尾决定尚属后续设计。

## 给家长的便条

> 我是守灯员阿舟。放灯的小棚要修屋顶，我把灯搬去避雨了。暂存屋的窗户是圆形。搬运标签上的记号和屋子门上的记号一样。请帮灯会组织者确认是哪间屋，并请他们联系我检查、送回灯会。

先读给孩子听，再问：“便条告诉我们窗户是什么样的？你手里的标签上有什么？”先听孩子回答或指认，再一起比较。

## 给孩子的图卡

给孩子[搬运标签](dongfang-weicheng-label.svg)，再展示[三间小屋](dongfang-weicheng-cards.svg)让全家一起观察。孩子不认识字母时，直接指着小屋作答即可。

孩子的任务是：观察标签、告诉家长看见了什么、在小屋图上指出选择，并用说话或指图说明理由。

如果有两个孩子，一个描述标签，一个寻找符合窗户条件的房屋；最后互相检查，再共同选择。下一环节交换任务。

## 引导者流程与答案

1. 发便条和图卡，从开始读便条时计时。
2. 观察谁先提供信息、孩子是否参与比较，避免提前评价猜想对错。
3. 请家庭选择一间小屋，并说明两个依据；允许指认代替完整句子。
4. 选择与依据对应后，出示代表灯的纸片：“组织者按你们确认的位置找到了灯，联系阿舟检查后，就可以送回灯会了。”
5. 问孩子：“灯为什么被搬走？”再问全家：“你们各自找到了哪一条有用的信息？”记录反应与总用时。

答案是 C 屋：A 是圆窗但只有一颗星；B 有两颗星但窗户是方形；C 同时满足圆窗和两颗星。家长的文字信息提供窗户条件，孩子的标签提供星星条件，任一条件单独使用都留下两个候选。

灯由阿舟移走，目的是在小棚修屋顶时避雨。这个原因直接写在便条中，属于理解背景的检查，不计作孩子独立推理出的结论。

## 卡住时怎么帮助

先给家庭一点讨论时间，或等他们主动求助，再逐级提示。

- 一级：“我们先只看窗户，哪两间符合便条？”
- 二级：“这两间的星星一样多吗？再看孩子的标签。”
- 仍然困难：一起指认两个条件并完成，记为“共同示范后完成”，不让环节变成考试。

如果孩子很快完成，可追问“为什么另外两间不合适”。只改变解释深度，不临时增加陌生知识或暗藏规则。

## 怎样判断这次设计是否有效

目标用时5—10分钟，仅作为首轮预期，不设倒计时或竞速。更快完成本身不算失败，要结合参与过程判断是否过于简单。

| 观察项 | 记录内容 |
| --- | --- |
| 基本情况 | 日期、版本、孩子年龄、玩家人数；不必记录姓名 |
| 儿童行动 | 是否观察标签、提供信息、做出选择、指出依据 |
| 成人行动 | 是否朗读并提问，还是自己直接完成了选择 |
| 信息交换 | 窗户和星星两条信息是否都被说出或展示 |
| 推理理解 | 能否排除另外两间，而非碰巧猜对 |
| 背景理解 | 是否知道灯是暂存避雨，是否误以为在找坏人 |
| 提示与用时 | 独立完成／一级提示／二级提示／共同示范；实际分钟数 |
| 两个孩子时 | 两人各完成了什么，是否有一人一直旁观 |
| 体验反馈 | 最喜欢什么、哪里不懂，尽量记录原话 |
| 修改建议 | 把实际观察与建议分开，优先处理参与或理解障碍 |

目前所有观察项均为“未试玩”。纸面环节即使顺利完成，也只支持这个小环节的可理解性；还需补充不同操作的任务、现场观察与完整流程测试。
