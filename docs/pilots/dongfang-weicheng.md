# 东方卫城亲子剧本架构

工作名称：**《卫城小小守灯人：消失的迎归灯》**。架构版本：0.2；更新：2026-10-13。

本版依据[口碑与构成研究](../research/script-quality-and-components.md)，把首轮寻灯提案整理成可继续创作的整体架构。当前任务与验证状态只在[TODO](../TODO.md)维护。这里确定本版的设计基线，不代表完整剧本、家庭试玩或景区落地已完成；第一幕已细化为[0.2.1纸面原型](dongfang-weicheng-act1.md)，其余材料后续分轮制作。

## 1. 这一版希望一家人获得什么

**核心体验：孩子的发现被家人用上，一家人一起弄明白一件事，并亲手把它办好。**

以共同调查和协作为主，以轻角色扮演、温暖收尾为辅。角色有职责、在乎的事和影响结果的行动；第一版不采用复杂个人秘密、阵营对抗或长篇人物前史。

| 项目 | 本版方案 |
| --- | --- |
| 用户已确定 | 东方卫城试点；6—9岁孩子与家长；支持多人共创和反馈 |
| 玩家配置 | 一个家庭，1—2名孩子与1—2名成人，共2—4人；另设一名引导者 |
| 故事尺度 | 一盏灯、一次搬运、一次不完整交接；三个功能场景 |
| 主要问题 | 灯准确放在哪里？为什么搬走？怎样完成这次交接？ |
| 玩法变化 | 第一幕合并条件找位置；第二幕比较记录、还原因果；第三幕共同安排并完成交接 |
| 气氛 | 好奇、轻悬疑、合作、有发现感；不存在迫近的人身危险 |
| 目标时长 | 核心流程30—45分钟；含行走和休息约45—60分钟。均为设计目标，待实测 |
| 最小运行条件 | 纸面材料、一名按说明发卡的引导者；无需景区演员或数字系统 |

“东方卫城依托北塘古镇、项目涉及海防文化”的背景来自[天津经开区政务平台2026-08-14报道](https://www.teda.gov.cn/contents/13/113410.html)。本故事中的人物、迎归灯会、灯的用途、维修、仓屋和交接方法均为原创虚构，不是当地史实或景区现有活动。灯是节庆作品，不承担真实航海导航功能。

## 2. 从研究到本版的具体取舍

| 研究带来的要求 | 本版怎样落实 | 后续需要看见的证据 |
| --- | --- | --- |
| 先做好一种核心乐趣 | 围绕共同调查组织三幕，不同时追求重推理、催泪和竞技 | 家庭能说出共同发现或完成的具体事情 |
| 投入有回应、前段信息会回收 | 第一幕合并位置信息；第二幕将发现接入事件经过；第三幕由玩家完成新的完整交接 | 先前发现实际改变后续判断和操作 |
| 从玩家视角检查信息 | 区分直接获知、组合推得、仍不能断言的内容 | 玩家能指出依据，主持不用临时补规则 |
| 每人有行动，不只分字数 | 孩子观察、解释、选择；成人比较、质疑、检验安排 | 记录各人的实际贡献及等待情况 |
| 关系在行动中成立 | 见习守灯人与联络员相互核对，收尾具体说出对方的帮助 | 不依靠强制表白或煽情才能完成收尾 |

| 景点特征要有实际作用 | 留出真实观察替换位，但先用模拟图检验逻辑 | 现场特征确实参与判断，路线经过走测 |

以上是根据研究形成的设计判断，不能据此声称儿童适龄性或市场接受度已得到证明。

## 3. 故事主线与作者掌握的真相

**面向玩家的开场梗概：** 卫城正在准备一场迎归灯会，大家共同制作的迎归灯却离开了原来的小棚。组织者收到阿舟签名的临时存放单，上面写着“圆窗”，配套的位置图签却没收到。图上有两间圆窗屋，究竟是哪一间？一家人组成守灯小队，受托核对位置、弄清搬运经过，再帮助大家把灯会安排好。

阿舟是当值守灯员。**他的姓名在开场就已知，不再把“猜出搬灯者”当成谜题。** 把精力留给信息合并、因果理解和共同操作，避免为增加谜题强行加入嫌疑人。

### 作者时间线

| 顺序 | 实际发生的事情 | 对玩家意味着什么 |
| --- | --- | --- |
| 1 | 迎归灯原本放在准备灯会的小棚中；棚顶随后需要检修 | 原放置安排发生变化 |
| 2 | 阿舟按检修要求把怕雨的灯包好，移至圆窗、门上两颗星的 C 屋暂存 | 灯的位置变化有保护物品的理由 |
| 3 | 写有“圆窗”的文字联送到组织者；同一盏灯的“两颗星”位置图签留在搬运夹里 | 两条必要的位置条件只送到一条 |
| 4 | 组织者凭文字联只能在 A、C 两屋之间判断，无法确认取灯位置 | 委托小队核对，而不是宣布发生盗窃 |
| 5 | 小队补齐信息，找到灯的存放位置，并用检修与搬运记录还原经过 | 第一幕的位置判断与第二幕的事件解释接起来 |
| 6 | 原棚仍在检修，故事中另有已确认可用的临时集合台。小队完成取灯交接并选定收尾方式 | 解决问题包含把信息交清楚和作出安排 |

不再追查图签为何留在夹内；现有证据只支持“没有随文字联送达”。不补写风吹、故意隐瞒或谁应该受责备。阿舟的搬运记录直接记载“防雨暂存”，这是记录提供的目的，不包装成玩家仅凭外观猜透人物内心。

场内的组织者由引导者用短句代表；阿舟通过记录出现。玩家不需要找到真实工作人员。若提前提出相关问题，引导者可以提前给相应记录，不为维持幕次故意扣住已问到的资料。

## 4. 谁来扮演，为什么彼此需要

两种轻角色同属一支小队，互为搭档。岗位不与性别绑定，不要求儿童独立阅读或背台词；玩家可指认、摆卡、口述，也可交换工作。

| 角色 | 身份与在乎的事 | 第一幕贡献 | 第二幕贡献 | 第三幕贡献 |
| --- | --- | --- | --- | --- |
| 见习守灯人，通常由孩子担任 | 今天第一次加入守灯小队，希望找到灯，让大家看到它，也希望自己的发现有用 | 描述图签、比较房屋，选择并指出依据 | 摆出事件关系，提出“可能是因为……”并随证据修正 | 表达收尾偏好，给取灯通知补图示，参与核对与揭灯 |
| 灯会联络员，通常由成人担任 | 与见习守灯人共同受托，希望安排有依据、通知让接收者看得懂 | 从文字联提取条件，与孩子一起排除候选 | 比较检修对象、搬运目的和收件内容，检查解释是否得到支持 | 检查取灯与集合条件，与孩子商量，向接收者交接并听回读 |

成人的任务不止是朗读。即使引导者把文字全部读出，成人仍须比较记录、检查解释、协商安排。孩子的任务不止是递图卡，后两幕还要解释、修正和决定。

**人数变化只拆分工作，不增加必不可少的身份或独占线索：**

- 1孩1成人：各承担一个岗位；共同完成每幕判断。
- 2孩1成人：孩子分别先提出判断、核对证据，下一幕交换；成人承担联络员工作。
- 1孩2成人：成人分别提出解释、检查依据，下一幕交换；孩子保留观察、判断与表达选择的机会。
- 2孩2成人：先两两查看不同材料，再全家合并；下一幕换任务，避免一对先做完而另一对只听答案。

材料可以公开分享，岗位不构成保密或禁止帮助的规则。不能保证成人在能力上无法独自解题；设计目标是让孩子的贡献自然被使用，并在试玩中检查是否发生。若参与家长兼任引导者，其已知答案的体验须单独记录，不能当作成人盲玩结果。

## 5. 三幕怎样连成一次体验

开场先用约2—3分钟认识任务、岗位和材料规则。以下时长均为预计；初次试玩记录实际时间，不按倒计时催促。

| 幕与当前问题 | 家庭行动及新信息 | 必须看得见的成果 | 推进条件与预计用时 |
| --- | --- | --- | --- |
| 第一幕：拼出位置。灯究竟在哪一间？ | 成人查看“圆窗”文字联；孩子在搬运夹材料中找到目标灯对应的两星图签；全家在 A/B/C 图上合并条件 | 在图上标出 C，并指出圆窗与两星两个依据；引导者给出库内核对结果，确认灯仍在那里、完好 | 选定位置并说明依据，或经提示、示范后完成。7—10分钟 |
| 第二幕：还原经过。为什么要把灯移开？ | 比较棚顶检修资料与“防雨暂存”记录，区分“修棚”与“修灯”；回收第一幕已经能发现的图签缺失，将其接入完整经过 | 一张三步经过图：“棚检修→移灯暂存→通知少图签，无法确认位置”；用实际材料支持连线 | 理解主要因果即可；缺图签是前幕结论回收，不重新设为猜谜关卡。需要示范可继续。10—14分钟 |
| 第三幕：让灯会继续。怎样交接，怎样一起亮灯？ | 确认原棚尚不能使用、临时集合台可用；填写从 C 屋取灯到集合台的交接板；共同选收尾顺序；让接收者按交接内容回读 | 完整取灯通知、接收确认，以及按家庭选择执行的亮灯收尾 | 接收者能确定取灯点与送达点，双方完成一次核对后，由组织者模拟取灯。含结尾约10—15分钟 |

每幕都走完“得到材料→提出观察或判断→共同比较→采取行动→看见结果”。儿童贡献应影响位置、事件解释或安排，不以盖章数量替代实际参与。

### 第二幕如何避免只是听答案

先请家庭用手头材料提出解释，再给需要核对的检修和搬运资料，或在家庭尚无猜想时主动交付。孩子可以先摆图、成人检查依据，也可以相反。

“灯坏了所以拿去修”和“棚在修所以灯先移开”可作为主持备用的比较问题，不强迫玩家先猜错。记录明确维修对象为棚顶、灯具状态完好，并记载防雨暂存目的。这里只要求还原记录支持的经过，不将其包装成排除了所有想象可能的刑侦证明。

图签缺失在第一幕结束时已能发现，不作为第二幕的新反转。还原时把“应有文字联和图签、实收只有文字联、图签留在搬运夹”接入经过即可；玩家若已经解释清楚，不重复提问拖长时间。家长不能只念一句“原来是误会”，孩子也不必独自讲完全部真相。

### 第三幕的选择怎样产生结果

取灯位置与正确交接属于必须核对的事实；亮灯方式是可以协商的偏好。第一版提供两种都可行的收尾：

- **先亮灯，再讲发现：** 接收确认后先翻开亮灯图，全家再用经过图介绍各自的一项发现。
- **先讲经过，再一起揭灯：** 接收确认后先用经过图带组织者重走发现过程，再共同翻开亮灯图。

选择改变实际执行的收尾顺序，主持按选择发放对应结尾，不评价哪一种更高尚。儿童可用指图代替发言，成人也不能代替全家作决定。这是规模很小的呈现选择，先检验协商和掌控感；暂不声称具有重大剧情分支。若试玩觉得差异无感，下一轮再增强选择，而不是先增加多个结局。

交接板须含：目标灯图案、取灯点的圆窗与两星两个条件、明确的临时集合台送达标记，以及接收确认。也接受能独立、清楚表达同一位置的自创画法，不要求照抄模板。组织者根据交接板在图上指出 C 与集合台，玩家核对。接收者只按板上实际提供的信息回读；信息不足时指出缺项，请家庭补齐，不凭前幕记忆代填。双方确认后才给出“已取到并送达”的故事回执，继而亮灯。第一幕用过的信息在这里再次发挥作用。

下表是六组材料的内容合同，不是六张已经制作好的卡；排版、字数与具体卡数留到下一轮。主持用清单保证关键材料交付，不能靠玩家碰巧在真实场地搜到才推进。

| 编号、首次出现 | 内容与取得方式 | 实际支持的判断 | 呈现与后续用途 |
| --- | --- | --- | --- |
| M1 开场：委托与身份 | 目标灯图案、空灯座、组织者委托、岗位与公开规则，由引导者交付 | 灯不在原处、需要核对位置是背景事实 | 目标灯图案贯穿 M2/M3/M5/M6，确保材料对应同一物品；认识岗位 |
| M2 第一幕：组织者收件包 | 阿舟署名的文字联写“圆窗”；说明地点须由窗形和门记号共同确认，并应附图签；收件状态图明确实际只收到文字联 | 阿舟经办是已知事实；圆窗单独留下 A/C；尚不能确认是哪间 | 成人先查看，可口述。第二幕再次核对实际收件内容 |
| M3 第一幕：搬运留存包 | 搬运夹中有目标灯的两星图签；另有共用三屋图：A圆窗一星、B方窗两星、C圆窗两星。来源位置在卡面标明 | 两星单独留下 B/C；结合 M2 才唯一确定 C；图签并未随文字联送达 | 图签先交孩子，三屋图共看；用图案与数量，不以认字母或辨颜色为门槛。后两幕继续保留 |
| M4 第二幕：检修资料 | 棚顶开工前后图与检修告示，明确棚内怕雨物品需移出，原棚尚未完成验收、暂不可用 | 原处不适合继续存灯；被维修的是棚顶 | 孩子指认变化，成人核对告示对象；支持因果解释与第三幕场地条件 |
| M5 第二幕：搬运记录 | 阿舟的当班记录：接检修通知后，将同一图案的迎归灯包好、防雨暂存；灯完好。配可摆放的事件图 | 移灯发生在检修通知后，防雨是直接记载的目的；与 M4 合成事件经过 | 成人比较记录，孩子排列并解释；只要求有依据的先后，不强排没有证据的细小时间顺序 |
| M6 第三幕：行动与交接包 | 临时集合台标记及可用说明、交接板、接收回读指引、送达回执和两种收尾顺序卡 | 怎样完整传达取灯与送达信息；玩家选择影响接下来的呈现 | 共同制作、执行与核对；回执确认既有推导，不补充决定前幕答案的新规则 |

第一幕的库内核对结果由主持在玩家确认 C 后提供：“对应图案的灯在这里，状态完好。”这是结果反馈，不是额外解题条件；M5随后提供可对照的记录。

A/B/C为本架构的编写与核对代号；后续玩家图面暂不印字母房号，以图形和位置指认即可。若后来增加统一房号，应接受准确房号作为有效交接，不能为逼玩家用两个条件而拒绝其他足够清楚的表达。

### 用玩家视角查四个关键问题

| 要回答的问题 | 玩家届时已经获得的依据 | 结论强度与边界 |
| --- | --- | --- |
| 准确位置在哪里？ | M2圆窗＋M3两星＋三屋图；定位规则在作答前明确 | 两条件交集唯一为 C。A、B各只符合一个条件 |
| 为什么移开？ | M4棚顶检修要求＋M5搬运顺序与防雨记录 | 理解并连接记录中的因果；不是独立猜中动机 |
| 通知哪里出了问题？ | M2应附与实收内容＋M3图签实际留存位置 | 能确认图签未一起送达；不能据此断言遗落的心理原因或故意行为 |
| 怎样避免同样的误会？ | 前幕发现＋M6交接要求＋接收者实际回读 | 用一次完整交接检查信息是否足够，而非只回答口号 |

资料在本故事中为可靠记录，没有伪造、变装或隐藏的识字知识测试。开始即说明可共同查看、请求朗读与提示。正确的提前推断予以承认，不因尚未到某一幕而否定。

## 7. 引导与景点结合的边界

引导者负责发卡、简单代表组织者、提供反馈、提示和记录。导航直接说明，推理问题留给玩家；不把“下一张卡在哪里”或“下一站怎么走”当作核心难题。

| 情况 | 处理方式 |
| --- | --- |
| 卡住 | 先问要核对哪条信息；再指出两条应比较的材料；仍困难时一起指认或示范。记录提示等级，继续故事 |
| 选 A 或 B | 复述该屋实际特征，邀请核对另一个条件；不扣分，不宣布失败 |
| 第二幕解释不完整 | 保留已经成立的发现，补看缺少的记录；不让复述题阻断取灯和收尾 |
| 漏拿材料 | 用发放清单补齐同版材料；缺失图签不能变成运气关卡 |
| 阅读或表达困难 | 引导者朗读，允许指图、摆卡或搭档代述，不要求独立表演 |
| 有人暂时离开或注意力转移 | 留下已知结论板，用“现在知道什么、接着做什么”两句话帮助重新加入 |
| 休息或缩短 | 可以暂停后续玩；简化复述和展示长度，保留孩子的一次判断与完整交接，并记录为缩短版 |

三幕是功能场景，可以在一张桌上完成；现场也不必对应三个相距很远的点位。A/B/C屋及临时集合台均为模拟位置，不能用图卡指引游客进入真实建筑。

| 场地替换位 | 勘察后要接入的真实内容 | 目前状态 |
| --- | --- | --- |
| 第一幕的位置观察 | 儿童从正常游览区域能看清、稳定存在的建筑或标识特征；重新设计候选，使两条条件仍需合用 | 未采集；圆窗和星星只是纸面占位 |
| 第二幕的地方联系 | 有出处、能自然解释守望或协作主题的地方资料，必要时调整虚构故事的背景表达 | 只有项目背景来源；不编造古代用灯或交接制度 |
| 第三幕的停留与收尾 | 实际适合家庭讨论的位置，核对步行、停留及点位不可用时的替代安排 | 未走测；临时集合台不指某座已获准使用的设施 |

现场版至少要让一项核实过的可见特征参与判断。若只能更换地名、沿路读同样卡片，就仍是可移动的纸面游戏，不能称景点定制已经完成。桌面替代能保留玩法，但不能替代文旅适配验证。

## 8. 接下来怎样逐步细化

第一幕现行文稿、发卡与提示见[0.2.1主持说明](dongfang-weicheng-act1.md)，配套[玩家卡片](../../output/pdf/dongfang-weicheng-act1-cards.pdf)和[空白观察表](dongfang-weicheng-act1-feedback.md)。下面保留各轮的设计目标，实际制作与试玩是否完成只看TODO。

本版先采用寻灯主线、轻角色、三幕结构、图签未送达的原因链和引导者发卡方式。它们是可修订的创作基线；真实路线、材料难度、实际时长、人数适配和结尾选择效果仍待验证。

| 下一轮 | 只推进的重点 | 产物与进入下一步的依据 |
| --- | --- | --- |
| 1 第一幕原型 | 把 M1/M2/M3 写成可发给家庭的短卡，补开场、提示和记录表 | 检查两条件共同作用；默认卡面不提前写明修棚与防雨目的，允许玩家提前发现交接缺失；与家庭试一次，观察贡献与卡点，先改明显问题 |
| 2 第二、三幕原型 | 制作 M4/M5/M6、经过图、交接与收尾指引 | 分别检查孩子是否参与解释、成人是否需比较判断，以及接收回读和选择是否有体验差异 |
| 3 完整桌面体验 | 串联三幕，交给非作者引导者试带 | 记录全程时间、等待、提示、投入与复述；先修推进及参与问题，再润色与美术 |
| 4 人数与场地适配 | 可并行采集真实点位；纸面逻辑稳定后接入实景，覆盖实际计划接待的家庭组合 | 年龄与人数分开记录；替换场地信息后重新核对证据与路线，并完成现场试玩 |

试玩记录至少包含版本、日期、孩子年龄、各角色实际行动、判断依据、提示等级、用时和原话。一次家庭完成只能帮助改稿，不能覆盖全部6—9岁和2—4人组合。每一名参与者都应有一次改变判断或安排的贡献；是否持续参与仍须逐幕观察。

共创时由一名整合者维护本页的主线、规则和材料编号；协作者分别补角色材料、场地资料、题面与引导、试玩观察。改动时注明影响哪一幕、哪组材料和哪个结论。先记录实际行为，再写修改建议；当前采用的版本和下一步统一回到 TODO，不另开进度表。

旧版[5—10分钟小样](dongfang-weicheng-mini-test.md)与图卡仍可独立用于信息交换练习，但其便条已直接说明搬运原因，**不可原样作为本架构第一幕**。原设计已保存为[改写前快照](../archive/2026-10-13-pilot-before-architecture.md)；本轮取舍与检查见[架构记录](../archive/2026-10-13-pilot-architecture.md)。
