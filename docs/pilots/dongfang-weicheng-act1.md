# 第一幕试玩说明：拼出灯的位置

版本：0.2.1；2026-10-13。对应[整体架构0.2](dongfang-weicheng.md)的第一幕。当前制作、验证与待办统一见[TODO](../TODO.md)。

本稿可供一名引导者带一个家庭做纸面试玩。它细化了角色、材料和操作，但尚无家庭实测；文末对话是创作示例。故事、房屋和标记均为虚构，不依赖真实景区点位。

## 先拿这三份材料

- [玩家卡片PDF](../../output/pdf/dongfang-weicheng-act1-cards.pdf)：共3页，A4单面打印；第一页两张角色卡，第二页两张线索卡沿虚线剪开，第三页委托与三屋图整页保留。可黑白打印。引导者先分好材料，再交玩家。
- [卡片文稿](dongfang-weicheng-act1-cards.md)：供共创修改与主持准备，含制图说明，不整页发给孩子或家长。
- [空白观察表](dongfang-weicheng-act1-feedback.md)：试玩时记录行为、提示与用时，不先填写理想结果。

额外准备一张折纸或任意文件夹，外面写“搬运夹”；把孩子的图签放进去。没有夹子就将图签扣放，并口述其来源。手指即可选屋，不需要购买道具。

最小组合为一名6—9岁孩子、一名参与家长、一名引导者，共3人。引导者不算家庭玩家。参加的家长不预读本页答案或整套卡片；若家长兼主持，记录为“家长已知答案”，只观察孩子的理解与行动，不据此判断盲玩家长的体验。

准备约3分钟，开场约2—3分钟，第一幕目标7—10分钟，另留2—3分钟反馈；均为估计，不是必须占满的时长。熟练家庭可能很快完成，快速且有依据的判断不算失败。首次试带可以暂停核对说明。

## 主持先知道的答案

作者代号A/B/C依次对应图中左、中、右；玩家图面没有这些字母。

- 只看家长文字联的“圆窗”，左、右都可能。
- 只看孩子图签的“两颗星”，中、右都可能。
- 两个条件一起看，只剩右边的屋子：圆窗、门上两颗星。
- 阿舟署名在开场已知，不需要猜搬灯者。图签没送达也可在本幕发现，不藏成后幕反转。
- 本幕确认灯仍在该屋、状态完好；不在默认开场讲出搬运原因，不表演已经把灯取回或点亮。

关键规则必须先可见：位置要同时核对窗形与门记号，图签对应哪件物品由灯身波纹标记确认。确认依据比猜中某个位置更重要；指图与摆卡同样有效。

## 材料怎样发

| 材料 | 谁先拿 | 何时出场 | 主持检查 |
| --- | --- | --- | --- |
| K1见习守灯人角色卡 | 孩子；两孩可共看 | 开场 | 可朗读，不强迫孩子读字 |
| K2灯会联络员角色卡 | 家长；两成人可共看 | 开场 | 家长也须提出、检查判断 |
| K3委托＋K6三屋图整页 | 全家共同看 | 开场 | 三屋无灯、无高亮或答案字母 |
| K4文字联＋收件条 | 家长 | 开始调查时 | 只有圆窗条件，没写星数 |
| K5位置图签，放在搬运夹中 | 孩子 | 与K4同一阶段 | 与灯的标记相同，只提供门记号，没写窗形 |

分开先拿是为了给每人一个进入点，不是保密。两人可展示、交换或共同看；主持不遮眼、收走线索或要求背下来。整个试玩用同一版本的新材料，不能混用旧0.1小样的便条和图卡。

## 可以照着带的流程

### 1. 接下委托

摆出公共页，发角色卡。主持指着灯的波纹标记，读：

> “欢迎加入守灯小队！今天要找的是这盏迎归灯。灯不在原来的小棚里了。我收到了阿舟签名的存放单，却少了一张位置图签。请你们一起查收件材料和搬运夹，帮我确认它到底放在哪间屋。”

接着说：

> “见习守灯人可以先看图、说发现；联络员查看文字、比较可能的位置。所有材料都能一起看，可以指图，也可以随时请我帮忙读。你们一起决定。”

让孩子任选说“接下任务”、点头或拿起角色卡，不设置表演门槛。主持记录开场起点；不预告圆窗或星数。

### 2. 各自取得一条信息

把K4给家长，把装着K5的搬运夹给孩子；两份同阶段交付，不让另一人空等。说：

> “这是我收到的文字联；这是今天的搬运夹。请看看里面的图签是不是对应同一盏灯，再一起比较屋图。”

孩子或家长需要时，指出各卡相同的灯身波纹，说明它只表示“同一盏灯”。取得图签是查阅材料，不算独立解出谜题。

先留出看材料与交谈的空间。若不知道如何开始，可按角色卡邀请：

> “把你先看到的一条信息告诉搭档。先只用这条信息，图上哪些屋子还有可能？”

邀请双方都提出发现即可，不要求依次背完两张卡。如果孩子已经把所有信息合并，直接进入核对，不强行退回发言顺序。

### 3. 共同选择并检查

请家庭在图上指出选择，并把用到的两条材料摆在旁边。主持说：

> “请选定一间。你们用的是哪两条信息？可以用手指给我看。”

家庭应把“文字联的圆形窗户”对应到右屋窗，把“图签的两颗星”对应到右屋门。主持接受清楚的指认，不要求孩子说出完整推理术语。

如果已选对但理由不明，只追问一次：

> “再看看另外两间，哪条线索让你们没有选它？”

能说明或指认差异即可。不要变成三轮同题考试。若答案由家长先报出，仍邀请孩子核对图上特征；记录“成人先给答案”，不把儿童随后认同算成独立推得。

### 4. 给出结果，结束第一幕

两条依据都对应后，或在共同示范后，主持代表组织者反馈：

> “我已经请人按你们说的位置核对了：圆窗、门上两颗星的屋里，确实放着这盏迎归灯，灯也完好。准确位置确认了！”

用实际发生的动作回应贡献，例如：

> “你指出了门上的记号，搭档补上了窗户条件。两条信息合起来，才让我们选定这一间。”

若过程不同，照实际说，不虚构孩子独立发现，也不要求说谢谢或表白。让家庭保留线索；实际只试玩本幕时明确收束：

> “这一幕的任务完成了。我们已经知道灯在哪。为什么搬灯、接下来怎么安排，是后面要继续核对的事情。今天先试玩到这里。”

然后收集短反馈。本轮不直接演第二幕；主动问到的事情按下方答疑处理。

## 卡住、抢答或提前追问怎么办

提示不是按秒自动给。先看家庭是否仍在尝试；他们求助，或明显停住且愿意接受帮助时再升级。记录最高等级和具体话语。

| 等级 | 主持可说的话或动作 | 记录口径 |
| --- | --- | --- |
| H0 无提示 | 仅按正常流程发卡、朗读委托和说明操作 | 家庭自行判断 |
| H1 提醒看材料 | “再把文字联和图签放到屋图旁边，看看有没有还没用上的信息。” | 提醒后判断 |
| H2 明确比较 | “文字联说的窗户，对应哪两间？图签上的门记号，又对应哪两间？” | 分步比较后判断 |
| H3 共同示范 | 主持与玩家一起指：左屋星数不符、中屋窗形不符、右屋两条都符 | 示范后完成，不计作独立解出 |

朗读卡上原有文字、把字体放大不自动算推理提示；若额外指出条件或候选，就记录相应等级。

| 情况 | 处理 |
| --- | --- |
| 选左边 | 不先说“错了”；请家庭核对所选屋的门记号与图签。若点明要看另一条条件，记H2 |
| 选中间 | 请家庭核对窗户与文字联；点明条件记H2 |
| 只说“右边”但没有依据 | 邀请指出两条材料；仍无法对应时可提示或示范，不能按猜中计成功 |
| 家长抢先说答案或拿走全部材料 | “先听听见习守灯人手里的发现，再一起核对。”允许孩子拿回图签或指图，不要求假装没听到答案；记录这次干预 |
| 孩子独立看完所有材料并解出 | 承认发现；成人承担排除另一候选和核对依据。记真实贡献，不强造信息隔离 |
| 两个孩子 | 一个描述图签，一个先在三屋图上比较，再分别核对左屋的星数和中屋的窗形；同一幕内就给两人行动机会 |
| 两个成人 | 一个提取文字条件、说明候选；另一个听完儿童发现，检查最终选择的依据，不抢着提前报答案 |
| 只需很短时间就完成 | 正常收尾并记录。可问“还有哪间看起来像，但不符合另一条线索”，不临时加密码或拖时 |
| 想去真实建筑找灯 | 说明本次是纸面试玩，只需指图，位置由故事里的组织者核对 |

**提前追问的可靠回答：**

- “为什么搬灯／能直接问阿舟吗？”——“可以查他的记录。记录写着：棚顶检修，阿舟把灯包好，防雨暂存。我们还要核对准确位置。”这是根据主创已确定真相提供的记录摘要，记为“原因提前披露”；以后接第二幕时不重复制造悬念。
- “图签为什么留在夹子里？”——“现在的资料只说明它留在夹子里，没有写具体怎么留下的。”不临时补编风吹、故意藏起来或谁粗心。
- “直接让阿舟告诉我们在哪间，不就行了？”——“可以。今天的试玩是用他留下的单据和图签来核对；如果你想我直接转述，我可以告诉你，再一起看看记录是否对得上。”玩家坚持时直接说明圆窗、两星，记为“直接答案后核验”，不再计作独立定位。这个偏好本身也是试玩反馈。
- “两间都圆窗，随便去一间看呢？”——承认这是可行的实际办法；说明当前纸面任务可以把两份信息合起来一次确认。如果玩家更想试探，按所选屋反馈其真实特征，不编危险来阻止；记录“逐间尝试”与最后是否理解两条件。

## 一家人可能怎样玩：虚构示例

以下为了展示流程而编写，不是实测记录，也不是玩家须照念的台词。示例中的“左、中、右”对应玩家图面；家长可以自然提问，但不需要连环考问。

| 谁 | 说什么／做什么 | 这一刻的作用 |
| --- | --- | --- |
| 主持 | 发角色卡、公共页、文字联和搬运夹：“请一起核对灯的位置。” | 交代目标与材料来处 |
| 家长 | “我这张写圆窗。左边、右边都像，现在还不能选定。” | 提供一条信息，公开未解决的问题 |
| 孩子 | 打开夹子：“这里有两颗星！中间和右边的门上都有。” | 观察并提出候选 |
| 家长 | “我先把中间排除，它的窗是方的。” | 用自己的条件检查孩子的候选 |
| 孩子 | 指右屋：“这间两条都对。左边只有一颗星。” | 合并并解释选择 |
| 主持 | “请把两条依据指给我看。” | 检查是否有依据，而非碰巧猜中 |
| 家庭 | 指图签、文字联和右屋相应特征 | 将信息对应到结论 |
| 主持 | 读库内核对结果，具体回应两人的贡献 | 给出行动结果，结束本幕 |

更常见的非理想路径也允许发生：家长先选右屋→主持邀请孩子核对→孩子指出两星→家长核对圆窗。这个过程能完成本幕，但只能证明“孩子参与核验”，不能证明孩子独立完成定位。把真实路径记下来，才知道下一版改哪里。

## 玩完只问三个问题，再改一个主要问题

1. 对孩子：“刚才哪一个发现是你告诉搭档的？”允许指卡；再问哪段想继续玩、哪段不想。
2. 对成人：“哪条信息让你的判断发生了变化？哪里像在调查，哪里像在教孩子做题？”
3. 对全家：“如果再玩一次，最想改哪一个地方？”记录原话，建议和实际行为分开。

用观察表区分：有依据且共同参与、成人完成而孩子旁观、猜中但理由不明、提示或示范后理解。答对率与用时不能单独说明好玩。

本轮重点看两件事：孩子的图签信息是否实际被使用；成人是否根据这条信息作出或检查判断。若两人都能完成但觉得太像练习题，下一轮应调整情境行动和反馈，不简单增加阅读量或谜题数量。先根据一组家庭的行为修明显问题，再用其他年龄、人数的家庭复测。
