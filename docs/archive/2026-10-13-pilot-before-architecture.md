# 东方卫城亲子试点设计

第一轮先做一个孩子能主动参与、家长也需要动脑的短故事。用纸面试玩发现问题，再把成立的玩法放到真实景点中。项目进度统一见[当前任务](../TODO.md)。

## 已确定的方向

用户选定东方卫城作为试点，面向带6—9岁孩子的家庭，支持多人共创与反馈。

东方卫城依托北塘古镇打造，项目定位涉及沉浸式海防文化。这为“港口、守望、协作”等创作主题提供了背景。[天津经开区政务平台，2026-08-14](https://www.teda.gov.cn/contents/13/113410.html)

下文人物、灯会、灯具用途及事件均为原创虚构设定，不是当地史实或景区现有节目。具体点位和路线尚待现场确认。

## 首轮设计卡

| 项目 | 暂定方案 |
| --- | --- |
| 工作名称 | 卫城小小守灯人 |
| 玩家 | 一个家庭，1—2名孩子与1—2名成人，共2—4人 |
| 体验目标 | 孩子发现关键细节，一家人通过交流还原事件，共同完成归还任务 |
| 气氛 | 好奇、轻悬疑、有一点意外，温暖收尾 |
| 时长 | 核心流程目标30—45分钟；连同行走、观察和休息约45—60分钟，待实测 |
| 范围 | 三个场景、一个核心谜团、一次共同选择 |
| 首轮物料 | 图像线索卡、成人短文字卡、任务地图、主持提示与结尾卡 |
| 引导方式 | 纸面试玩由一位引导者发卡；完整版本是否需要主持人，依据试玩确定 |

## 故事从一件小事开始

卫城要举办一场虚构的迎归灯会，大家共同制作的一盏灯却不在原处。家庭受托成为“守灯小队”，查明灯被谁移走、为什么移走，以及现在在哪里。

主创暂定真相：守灯员阿舟发现放灯的小棚要修屋顶，于是把灯搬到暂存屋避雨，留下的通知却没有完整传到组织者手中。不同的人只看见事情的一部分，因此出现了“灯不见了”的误会。查明经过后，家庭需要商量怎样把灯送回灯会，并留下清楚的交接记录。

这个真相只确定故事骨架。人物、时间线和全部证据应在后续创作中补齐，保证每个结论都能从玩家实际拿到的材料推出。[纸面微型环节](../pilots/dongfang-weicheng-mini-test.md)先测试其中的“寻找暂存屋”，不代表完整故事已经写成。

## 孩子和大人各自有用

| 参与者 | 掌握的信息与行动 | 给另一方的帮助 |
| --- | --- | --- |
| 孩子 | 观察图案、辨认物品、排列图片，指出哪里不一样 | 告诉家长现场到底出现了什么 |
| 成人 | 阅读短便条、比较记录、帮助把发生的事情排成顺序 | 解释文字信息，让孩子把观察和原因联系起来 |
| 一家人 | 互相描述线索，提出猜想，再用证据检查 | 一起回答“我们为什么这么认为” |

孩子可用指认、摆卡或口述参与，不把独立识字当作继续游戏的门槛。成人可以协助读题，但卡面不要直接包含完整答案。每个环节先邀请孩子指出一个细节，再请成人补充记录；这是引导方式，不强迫孩子独自表演。

同一条线索可以设置两层任务：孩子先找出图案差异，大人再结合时间或交接记录解释差异的意义。避免成人拿到一张卡就能解开全部谜团。孩子遇到困难时提供逐级提示，不把关键进展永久卡在某个人身上。

## 新手创作的顺序

此顺序适用于当前以谜团为入口的小样。其他类型也可先从人物关系或互动机制开始，再检查事件因果与玩家信息；不同入口见[研究结论](../research/script-quality-and-components.md)。

| 步骤 | 要回答的问题 | 最小成果与检查方式 |
| --- | --- | --- |
| 1 确定体验 | 给谁玩，希望一家人共同完成什么？ | 本页设计卡；参与者、时长和互动目标说得清 |
| 2 看场地 | 哪里适合观察、停留和交谈？有哪些当地特征值得进入故事？ | 三个候选点的照片或速写、可观察细节、步行实测；桌面小样可先用模拟点位 |
| 3 写真相 | 到底发生了什么？为什么？先后顺序怎样？ | 半页真相和简短时间线，先保持因果一致 |
| 4 倒推线索 | 玩家凭什么得出每个结论？ | 一张“结论—证据—取得方式—提示”表，不能只靠作者解释 |
| 5 分配任务 | 哪些信息孩子有，哪些成人有，他们为什么要交流？ | 儿童图卡、成人短文卡、一次共同判断 |
| 6 试玩再修改 | 哪里不懂、哪里无事可做、哪里最想继续？ | 原始观察记录，先修影响参与和推进的问题 |

可借鉴 Justin Alexander 的“三线索原则”：对关键结论准备多个独立的线索入口，减少漏看一条就无法继续的情况。它是设计经验，不是试玩成功的保证；第一版尤其要准备孩子能理解的提示。[原文](https://thealexandrian.net/wordpress/1118/roleplaying-games/three-clue-rule)

## 三个场景怎样与景点结合

以下是功能位置，不是已确认的真实地点。不能据此直接带领游客行走。

| 场景 | 家庭正在做的事 | 选点时要寻找的条件 |
| --- | --- | --- |
| 集合与发现 | 认识失踪的灯，观察最初的不同之处 | 能集中讲解、方便儿童观察且不妨碍通行的位置 |
| 调查与交换 | 孩子取得视觉信息，家长对照交接记录 | 存在清楚、稳定、可从正常游览区域观察的当地细节 |
| 还原与归还 | 排列经过，说明原因，完成共同决定 | 适合停留讨论及收尾的位置，可与集合处复用 |

勘察时重点寻找真实可见的建筑纹样、标识或空间关系，让其中至少一项参与推理。换一个景点仍能完全照搬的环节，需要继续增加当地特征。不要把未经核实的建筑年代、灯具制度或海防知识写成答案。

桌面图卡只验证交流与推理；它不能证明场地融合已经完成。现场版须重新核对儿童能否看见、步行与停留是否合适、拥挤或下雨时如何替代，以及是否需要景区配合。首轮不依赖景区演员、商户配合或预先藏物。

## 多人怎样共创

小团队可以一人兼任多项工作，但需要明确由谁统一维护真相和时间线。

| 分工 | 负责内容 | 交接时带上什么 |
| --- | --- | --- |
| 主创整合 | 真相、人物关系、时间线和版本取舍 | 当前采用的设定，以及更改影响了哪些线索 |
| 场地采集 | 候选点位、可见细节、行走条件 | 采集日期、来源、照片或速写、尚未确认的条件 |
| 玩法与角色 | 孩子和成人各自做什么，线索如何组合 | 任务目标、材料、正确推理、逐级提示 |
| 试玩观察 | 实际行为、卡点、参与情况 | 试玩版本、原话或动作、所用提示、改进建议 |

共创意见先记录为建议，经整合后再修改共享事实。每轮集中解决少数关键问题，优先顺序为：能继续玩、每个人有事做、证据说得通，然后再润色文字与美术。

反馈采用这个格式：版本与环节；观察到的行为；造成的影响；改进建议。例如“第一轮调查中家长把两张卡都拿走，孩子两分钟未参与；建议把现场图交给孩子描述”。把观察与建议分开，才能判断改动是否解决了真实问题。

## 首轮需要验证什么

- 孩子能否至少一次主动指出线索，并让它影响家庭判断。
- 成人是否需要听取孩子的信息，还是能自己读完所有材料得出答案。
- 家庭能否用材料说明理由，而不是猜中人物姓名。
- 卡住时哪一级提示有效，有无环节因阅读、看不清或走得太久而失去参与。
- 结束后孩子愿意讲述哪一段，成人觉得哪里有共同完成的乐趣。

这些是本试点的观察目标，尚无试玩结果。先记录一组家庭的过程用于改稿，再邀请其他家庭检验；单次完成不代表不同年龄与家庭都适用。
