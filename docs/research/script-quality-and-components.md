# 剧本杀口碑共性与完整构成研究

研究日期：2026-10-13。用途：为多人共创景点剧本建立判断依据。研究结论已用于后续的[东方卫城亲子剧本架构](../pilots/dongfang-weicheng.md)；当前进度见[TODO](../TODO.md)，逐项来源和访问边界见[本轮研究记录](../archive/2026-10-13-script-research.md)。

本轮最有用的结论是：评价较好的体验，往往能让目标玩家持续获得与其期待相符的回报，例如亲自推得结论、感到人物关系成立，或通过协作取得成果。故事、信息、行动与现场组织要共同支持这种回报。复杂、长篇、催泪、多反转和豪华演出并不自动带来好体验。

这是公开评价与创作者资料的定性归纳，不是全国排行、满意率统计或因果实验。

## 怎样理解本轮的口碑样本

以有具体游玩过程的署名玩家长评为主，核对同一作品不同账号的意见，同时保留批评。样本评价主要来自2024—2025年，包含2026年体验追评与2023年经典参照；评价时间不等于作品发行时间。未取得可独立复核的2026年全市场榜单，因此不称任何作品为“当前公认第一”。

作品评价主要集中在千岛，存在平台、公开发帖者和重度玩家的选择偏差。不同账号不等于已排除商业关系；也没有把门店好评自动算成原剧本的优点。无法核对样本量和统计口径的评分、营销榜、销量与复盘售卖页，不用于判断质量。

方法材料采用平台历史投稿规范、创作者访谈和游戏发行方的设计说明。它们可说明设计问题与交付方式，不能把旧收稿字数、时长或某一种玩法升格为今天的统一标准。

## 可以转化成创作原则的共性

### 先把一种核心乐趣做好

推理玩家可能愿意牺牲情感浓度换取持续推演，情感玩家可能更在意关系与演绎，机制玩家重视决策与配合。《六角馆》的正向评价就包含对少故事、高推理密度的偏爱。这说明“所有好本都人物丰满、情感浓烈、推理复杂”并不成立。[玩家依据](https://qiandao.com/post?postId=902509872422107332)

创作时先写清主要体验、次要体验和主动控制的负担。本项目需要重新检验“亲子一起冒险、协作发现”的定位是否比独立角色间的扮演关系更重要，不要求第一版同时具备所有卖点。

### 玩家的投入要获得回应

读到的信息、观察到的细节、作出的选择和付出的交流，之后应帮助玩家理解、决策、建立关系或形成氛围。并非每句话都必须是解题线索，但大段内容如果完全不影响体验，就容易变成负担。《逃脱2》对设定利用的肯定与《四季物语2》对无后续用途文本的批评构成对照。[推理评价](https://qiandao.com/post?postId=861337462297903604)、[机制评价](https://qiandao.com/post?postId=903731686464841846)

检查办法：为每个主要环节写出“玩家做了什么，获得什么回应，下一步怎样用到”。回答不出来时，优先删减或重做。

### 用玩家视角检查信息是否公平

作者知道真实经过，不代表玩家能从现有材料推出来。案件型作品要检查证据是否已经投放、规则是否事先明确、其他解释能否合理排除。分幕新增信息可以产生新问题；它不应仅靠临时补规则否定玩家此前合理的推理。

百变大侦探的历史投稿规范明确区分作者视角真相与玩家视角推导。这是可以保留的设计要求，而非照搬该平台当时全部收稿条件。[投稿规范](https://www.taptap.cn/moment/15202017291011186?group_id=159848)

### 给每个人持续参与的入口

参与机会不等于每人字数、秘密或台词完全相同。重要的是每个阶段能否观察、判断、表达、协作或影响进展。纯推理本可以让玩家主要作为调查者；强调扮演的作品则需要更充分的角色目标与人物联系。

创作者猫司图通过人物关系组织故事，避免只有主角的体验被照顾；《白衣倾城》不同玩家对角色参与的分歧提醒我们，不能只从一个角色的好评推断全员体验。[作者访谈](https://www.chinawriter.com.cn/n1/2021/0727/c405057-32170976.html)、[玩家对照](https://qiandao.com/post?postId=845283182709360409)

### 让关系和情绪在行动中成立

情感目标需要在过程中铺垫：一起完成事情、互相回应、产生误会并理解，才使之后的情节有重量。仅在角色本上写“你很爱这个人”不足以保证玩家代入。《流芳》的好评特别依赖现场互动，同时批评文本关系铺垫，说明这两层应分别检查。[玩家评价](https://qiandao.com/post?postId=870793515699809941)

对亲子试点，可研究共同完成任务、记住对方的贡献和互相帮助；这些只是迁移建议，不能从成人情感本推定儿童一定会喜欢。

### 节奏要允许理解和重新加入

《死亡回响》的好评仍记录难度突升、疲劳与掉队。《无尽夏》的对照显示，推导顺序贴近作者思路而远离玩家思路，也会损害体验。因此应记录每阶段的阅读、交流、操作与等待，并设计渐进提示和重新加入的入口。[难度与掉队反馈](https://qiandao.com/post?postId=821874171058350824)、[玩家视角反馈](https://qiandao.com/post?postId=711370433894607924)

不要把“没找到下一站”和“还没推明白真相”混为一种困难。前者是流程导航，后者才可能是希望保留的推理挑战。GUMSHOE 设计文章也区分通往下一场景的指引和帮助理解事件的关键证据；这是邻近游戏设计经验，并非中国剧本杀统一规则。[发行方设计说明](https://pelgranepress.com/2020/02/21/clues-vs-leads/)

### 形式与物料应帮助体验

模型可以帮助理解空间，演绎可以承载信息，地图与卡片可以显示行动结果。选用它们时，应明确解决什么体验问题。景区版尤其要让真实观察参与故事：在不同地方扫码阅读同样的文字，还不足以证明场地与玩法结合。

最后一句是针对本项目的设计判断。可参考《六角馆》的空间表现与《四季物语2》的成果反馈，不能把成人室内作品的成功直接当作景点适配证据。[空间表现评价](https://qiandao.com/post?postId=867750684915689648)、[成果反馈评价](https://qiandao.com/post?postId=903731686464841846)

### 把运行方法写进交付物

《流芳》和《像素对决》的评价显示，玩家称赞的一场体验可能包含门店补写、演员发挥和规则改动。对共创项目，应该分别记录原稿版本、现场改动、引导方式和玩家组成，才能知道什么值得保留。[门店补写反馈](https://qiandao.com/post?postId=925732480344952873)、[改版与评分自述](https://qiandao.com/post?postId=749389256765607669)

建议由没有参与创作的人按材料试带一次，观察哪些地方必须临时打电话问作者。这是本项目的可运行性检查，不是关于所有好评作品都已如此测试的事实断言。

## 一个完整剧本杀要解决哪些设计问题

下面是综合框架。“需要”指功能要被解决，不要求拆成同样数量的文件，也不要求每种作品采用相同篇幅。

| 构成 | 要回答的问题 | 最小可检查产物 |
| --- | --- | --- |
| 体验定位 | 谁来玩，主要享受什么，人数与时长如何影响设计？ | 一页体验说明，含适合与不适合的偏好 |
| 世界背景与规则 | 事情发生在哪里，哪些常识适用，哪些设定例外？ | 简明背景、规则及真实资料与虚构的边界 |
| 核心事件与因果 | 到底发生了什么，为什么值得玩家关注？ | 真实经过、关键时间线、动机和前后因果 |
| 玩家身份与角色关系 | 我是谁，我在乎什么，与其他人有什么关联？ | 角色卡与关系图；纯调查型可简化，扮演型需加强 |
| 目标与可采取的行动 | 现在该做什么，怎样调查、交流、选择或协作？ | 总目标、阶段目标、行动说明 |
| 信息与线索系统 | 谁在什么时候知道什么，怎样获得，能支持哪些结论？ | 信息分配表、线索清单、结论与证据对应表 |
| 互动与机制 | 为什么需要别人，怎样处理合作、交换、分歧或资源？ | 清楚的规则、反馈、结算与特殊情况说明 |
| 流程与节奏 | 如何开始、推动、变化、到达关键判断并收尾？ | 逐阶段流程、进入条件、推进条件和提示 |
| 结局与复盘 | 事件怎样结束，谜团如何解释，玩家行动得到什么回应？ | 结尾、推导说明、角色收束；有分支才需分支条件 |
| 主持与运行 | 换一位引导者能否组织，卡住或材料缺失怎么办？ | 主持手册、准备清单、备用方案；数字引导也需对应逻辑 |
| 物料与环境 | 哪些材料真正必需，如何发放、摆放和恢复？ | 角色本、线索卡、道具与音画清单；景区另附现场方案 |
| 试玩与修订 | 设计效果是否发生在真实玩家身上？ | 版本、观察、主持干预、问题与修改验证记录 |

角色本、线索、真相及主持手册的交付功能，可由[百变大侦探规范](https://www.taptap.cn/moment/15202017291011186?group_id=159848)与[剧本杀 App 历史约稿说明](https://www.taptap.cn/moment/93280377484873097)交叉核对；试玩记录与文旅现场方案是本项目为协作和落地增加的质量材料。

有角色扮演目标时，角色材料至少要让人知道自己的处境、目标、已知信息和可以先做什么。Freeform Games 的角色说明也把背景、目标、他人信息和初始行动列在一起，但其自由交谈玩法不代表所有国内作品。[发行方角色说明](https://www.freeformgames.com/faq/how-to-play-a-murder-mystery-game/)

## 实际应准备的交付包

1. 体验说明：对象、人数、时长、主要玩法与材料目录。
2. 主创总纲：世界规则、真实经过、角色关系与完整时间线。
3. 玩家包：公共规则与各角色材料，按实际发放顺序组织。
4. 过程包：线索、任务、事件与必要道具，注明发给谁、何时发、有什么作用。
5. 运行包：引导者流程、关键提示、推进与判定条件、常见偏离处理。
6. 收尾包：答案与推导、角色结尾、结局触发条件及解释方式。
7. 验证记录：版本、试玩反馈、现场改动与重新验证的结果。
8. 景区附加包：有来源的地方资料、真实点位和路线、行走与停留实测、点位不可用时的替代方案。

这些包可以合并为少量短文档。儿童玩家材料可以采用图像、口述和实物，不以长篇文字或文件数量作为完成标准。

凶手、命案、恐怖、隐瞒身份、阵营对抗、投票、战斗、积分、多结局、专业演员、服装和数字系统，都应由体验目标决定；它们不是这份通用检查框架的必选项。情感作品需要因果成立，但不必把每一段关系写成唯一答案题。

## 创作顺序有不同入口

上一轮建议的“先写真相”适合谜案驱动的练习，不是所有类型的通则。

- 推理入口：核心谜团与真实经过 → 玩家证据 → 角色如何卷入 → 互动、流程和复盘。
- 角色入口：人物想要什么、彼此是什么关系 → 什么事件迫使他们行动 → 信息、选择和结局。
- 机制入口：想让玩家进行哪种合作或博弈 → 规则与反馈原型 → 与之相配的故事、身份和流程。这一项是本研究的设计建议。

猫司图在访谈中明确采用人物关系入口；Freeform Games 的案件改写说明则采用事件与证据入口。两者支持“可以从不同位置开始”，最终仍要将因果、玩家信息与行动连接起来。[人物入口](https://www.chinawriter.com.cn/n1/2021/0727/c405057-32170976.html)、[案件入口](https://www.freeformgames.com/blog/writing-a-murder/)

## 对东方卫城试点的影响

本节记录形成0.2架构之前的评估，保留当时的设计问题。后续取舍与方案见[当前架构](../pilots/dongfang-weicheng.md)，本节不作为当前进度记录。

现有[纸面小样](../pilots/dongfang-weicheng-mini-test.md)仍未试玩。它将儿童标签与成人便条分开，测试的是合并两个条件、描述信息和共同选择。谁搬灯、为什么搬灯已由便条直接给出，因此不能把选对 C 屋当作完整事件推理的成功。

| 可继续用小样观察 | 小样不能单独证明 |
| --- | --- |
| 孩子是否提供信息，成人是否愿意听取 | 角色代入、人物关系与情绪体验是否成立 |
| 图形和短句是否容易理解，提示是否有用 | 完整故事能否保持兴趣，以及儿童适龄性已获验证 |
| 选择能否由两个条件共同支持 | 45—60分钟流程、真实路线与景点融合是否成立 |

下一步应先写清产品定位：以共同调查为主的亲子探索游戏，可以保留简化身份；以角色体验为主，则要补足每个人在乎的事、彼此关系与有意义的行动。二者可以组合，但应明确主要体验和验收方式。

针对6—9岁家庭，建议借鉴的原则是：可观察的信息、互补的贡献、简单的入门行动、可见成果、线索回收与共同选择。成人亲情本的好评不能证明适合孩子，成人本的长阅读、高强度情绪和时长也不能直接移植。

当前寻灯设定保留为实验素材，不视为已经选定的最终剧情。后续需要补齐体验定位、角色与目标、场景流程、玩家视角的证据链及主持方案，再组织家庭测试。

## 共创时共用的四张检查表

这是依据上述研究为项目整理的工作方法，不是行业统一表格。

| 表 | 最少记录的字段 | 解决的问题 |
| --- | --- | --- |
| 角色参与表 | 阶段、角色所知、目标、可做行动、需要谁、得到的回应 | 找出只旁观的角色，避免仅按字数判断戏份 |
| 线索推导表 | 线索、来源、发放条件、支持结论、所需前提、漏失补救 | 区分作者知道与玩家知道，检查关键推导 |
| 场景流程表 | 当前问题、玩家行动、新信息、推进条件、提示、预计与实际时长 | 避免走到现场不知道做什么，记录卡点与等待 |
| 试玩反馈表 | 版本、角色与玩家偏好、观察行为、主持干预、原话、改动、复测结果 | 分开作品问题、引导问题、同桌因素和个人偏好 |

主创统一维护真相与规则，协作者按表提出修改及其影响。反馈先写发生了什么，再提出解决办法；不同版本的评价不混成一条结论。
